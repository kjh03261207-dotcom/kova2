가장 안정적이고 광고가 없는 GitHub Pages(깃허브 페이지)를 사용하여 전 세계 사람들에게 웹사이트를 공개하는 구체적인 절차입니다.
Git 프로그램을 설치하지 않고, 웹사이트 화면에서 마우스 드래그앤드롭으로 올리는 가장 쉬운 방법으로 안내해 드립니다.
------------------------------
## ⚠️ 시작 전 필수 체크 사항

* 메인 파일의 이름은 반드시 소문자 index.html 이어야 합니다.
* 모든 파일(index.html, 1.html~5.html, ivy.mp3)이 한 폴더 안에 같이 모여 있어야 합니다.

------------------------------
## 1단계: 깃허브 회원가입 및 로그인

   1. GitHub 공식 홈페이지(github.com)에 접속합니다.
   2. 우측 상단의 Sign up을 눌러 이메일 인증을 거쳐 회원가입을 완료합니다.
   3. 가입한 계정으로 Sign in(로그인) 합니다. [1] 

## 2단계: 저장소(Repository) 만들기

   1. 로그인 후 우측 상단의 + 버튼을 누르고 New repository를 클릭합니다.
   2. Repository name에 원하는 영문 이름을 적습니다. (예: kova-project)
   3. 바로 아래 공개 범위 설정에서 반드시 Public(공개)을 선택해야 합니다. (Private으로 하면 웹사이트가 열리지 않습니다.)
   4. 화면 맨 아래로 내려가 초록색 Create repository 버튼을 클릭합니다.

## 3단계: 파일 업로드하기

   1. 새 저장소가 만들어지면 화면 중간에 파란색 글씨로 된 uploading an existing file 링크를 클릭합니다.
   2. 컴퓨터 탐색기에서 준비된 파일들(index.html, 1.html~5.html, ivy.mp3)을 모두 선택한 뒤, 브라우저 화면의 점선 영역으로 끌어다 놓습니다(드래그 앤 드롭).
   3. 파일 업로드가 완료될 때까지 잠시 기다립니다. (특히 ivy.mp3 용량이 크면 시간이 조금 걸립니다.)
   4. 화면 아래로 내려가 초록색 Commit changes 버튼을 클릭하여 저장합니다.

## 4단계: 웹사이트로 발행하기 (중요)

   1. 파일이 저장된 화면 우측 상단 메뉴에서 톱니바퀴 모양의 Settings(설정)를 클릭합니다.
   2. 좌측 메뉴 바에서 Pages 메뉴를 클릭합니다.
   3. Build and deployment 항목 아래에 있는 Branch 설정을 찾습니다.
   4. 현재 None으로 되어 있는 드롭다운 메뉴를 눌러 main (또는 master)으로 변경합니다.
   5. 우측의 Save(저장) 버튼을 누릅니다.

------------------------------
## 🎉 웹사이트 주소 확인 및 접속
설정을 마치고 1~2분 정도 기다린 후 화면을 새로고침(F5)하면, Settings > Pages 메뉴 최상단에 다음과 같이 내 웹사이트 주소가 담긴 박스가 생성됩니다.

🌐 내 웹사이트 주소: https://github.io

이 주소를 복사하여 사람들에게 공유하면 스마트폰이나 컴퓨터 어디서든 내가 만든 KOVA 안내 페이지에 접속할 수 있습니다.
안내해 드린 순서대로 진행하시다가 막히는 화면이나 특정 단계의 영어 메뉴 명칭이 헷갈리신다면 바로 말씀해 주세요! 해당 부분만 더 쉽게 보완해 드리겠습니다.

## 📝 나중에 다시 물어보실 때 함께 주시면 좋은 정보

   1. 작성하신 index.html 코드 전체
   2. 본인의 깃허브 아이디(Username)
   3. 만드신 깃허브 저장소 이름(Repository Name)
   4. 원하시는 댓글창 종류 (예: "로그인 필요한 깔끔한 창이 좋다" 또는 "익명으로 아무나 쉽게 쓰는 창이 좋다")
